= 资源管理模块

对应resource/目录

== 职责

. 资源指的是运行时资源，与资产作出区分，资源管理由resource manager负责，资产管理由asset manager负责
. 整个引擎的运行时资源缓存中心，负责资源缓存以便复用，负责资源生命周期管理，追踪，负责关联的GPU资源
. 同时负责资源对应GPU侧资源的生命周期
. 但是不负责材质系统，管线相关的资源
. 不负责场景图相关数据
. 不碰文件加载，只管理运行时资源
. 不做资产预处理，只管理处理成内部格式的数据

== 设计思路

=== resource的种类及实现方式

. 有两种资源类型
.. 基础类型: 不可拆分的最小单位类型，比如：单个纹理，单个buffer, 没有互相依赖的关系
.. 复合类型: 可拆分，但是一般看作一个整体的类型，比如：网格资源

* 复合类型应该由基础类型组成，复合类型引用基础类型，同时复合类型可以引用其他复合类型
* 每种类型都应该有引用计数，当有其他类型依赖时，计数加1，引用由句柄实现
* 复合类型之间可以交叉引用基础类型，基础类型不能有依赖，只能被依赖
** 复合类型可以引用其他复合类型
** 依赖链不能成环

. 本版应该有的基础类型:
+
* texture: 内部含有 rhi texture handle, 纹理相关属性如宽高等
* buffer: gpu中的一块内存，和相关属性比如用途，大小，rhi handle等
+
. 复合类型
+
* mesh: 引用buffer资源，如vertex buffer, index buffer等, 子网格包含在mesh中，记录对应buffer的偏移值，跨度， buffer可在不同mesh之间共享，用handle引用
* 预制件类型，如gltf, gltf看作预制件的一种， 可能包含: mesh, texture, 其中material通过材质系统关联，material是一个material handle
+
. 不包含的类型
+
* shader module, descriptor set, pipeline, xxx layout, 这些资源放在材质系统
+

. resource

=== 交叉引用方案

. 通过handle引用，需要经过rm让其增加引用计数，不能拷贝进去
. resource实例是唯一的，但是多个handle可对应同一个resource，resource的嵌套包含通过resource的handle对应，不能resource套resource
. 带引用计数

=== 如何存储

. resource在rm只有一份数据，外部多个handle可对应同一个resource
. 拷贝handle不会复制resource或者增加引用计数
. rm的handle是带类型的，方便区分不同类型的资源
. 为了避免ABA问题，及预留未来热重载扩展性，handle带分代信息，表示版本号
. handle的生成，包括id分发由RM负责

=== 如何判重

. 通过asset id判重

==== 待定问题

. 同一个资产是否可能需要多个resource?比如因为用途不同

=== 如何使用

. 引擎所有运行时资源都通过resource manager管理，外部不可自行持有或管理资源，而是通过handle访问
. rm能追踪资源状态，能够管理和分发handle
. 支持多线程异步，异步任务分派给job system执行
. 资源系统只依赖backend以便调度GPU资源，GPU侧资源会与运行时资源对应，关系是n对n
. 资源的真正卸载取决于引用计数

== 本版边界

. 暂不实现流式加载，热重载, 但是设计上预留空间，比如分代handle,资源带状态，resource类型和标签隔离能力等
. 暂不支持多线程
. 暂不集成内存分配器，job system

== 类设计

此处只展示核心类的核心成员，详见代码

[plantuml]
----
class Resource {
    资源保持唯一，基类
    此处有必要接口和实现分离，接口还带有AOP能力，可同时执行逻辑，方便debug
    资源的拥有者是Resource Manager,外部通过带类型的handle使用
    如果需要
    ==
    + void load()
    + void unload()
    ==
    # virtual void doLoad()
    # virtual void doUnload()
    ==

    - uint32_t mId
    - uint32_t mAssetId
    - string mName
    - ResourceStatus mStatus
}
class BufferResource extends Resource {
    buffer 属于基础资源，其可以单独存在，也可以被其他复合类型的资源包含
    通过handle表示关联关系
    ==
    Hw开头代表RHI资源句柄
    - HwBufferHandle mBufferHandle;
}
class TextureResource extends Resource {
    texture也属于基础资源
    ==
    - HwTextureHandle mTextureHandle
}
class MeshResource extends Resource {
    复合资源
    ==
    - ResourceRef<BufferResource> mVertexBuffer
    - esourceRef<BufferResource> mIndexBuffer
}

class PrefabResource extends Resource {
    复合资源
    ==
    - vector<ResourceRef<MeshResource>> mMeshes
    - vector<ResourceRef<TextureResource>> mTextures
}

class ResourceManager {
    包含判重和资源记录
    包含各种资源的存储结构
    基础和复合资源的计数是分开的，复合资源会同时更新包含的基础资源的计数
    Tag用于支持同种资源根据用途和生命周期特征不同分开管理
    Tag分为对内Tag和对外Tag，是一对多的关系
    ==
    - unordered_map<ResourceKey, ResourceHandle<T>> mRegistry
    - Pool<ResourceType> mXxxPool;
    ...
}

ResourceManager *-- BufferResource
ResourceManager *-- TextureResource
ResourceManager *-- MeshResource
ResourceManager *-- PrefabResource
----

== 核心调用链梳理

[plantuml]
....
actor developer as User
group 普通资产注册
     User -> ResourceManager: registerResource(T* asset)
     ResourceManager -> ResourceManager: 判重
     ResourceManager -> ResourceManager: 生成对应的Resource
     ResourceManager -> ResourceManager: 存储resource， 更新注册表
     User <-- ResourceManager: 返回Handle
end
group 复合资产注册
    User -> ResourceManager: registerResource(T* asset)
    ResourceManager -> ResourceManager: 判重
    ResourceManager -> ResourceManager: 生成prefab resource
    ResourceManager -> ResourceManager: 比如gltf解包为多种子资产
    ResourceManager -> ResourceManager: 把mesh拆分为buffer, 转换为buffer resource
    ResourceManager -> ResourceManager: 注册buffer resource(同普通资产注册)
    ResourceManager -> ResourceManager: 建立mesh引用关系
    ResourceManager -> ResourceManager: 建立prefab resource和mesh resource引用关系
    ResourceManager -> ResourceManager: 把texture转换为texture resource
    ResourceManager -> ResourceManager: 注册texture resource(同普通资产注册)
    ResourceManager -> ResourceManager: 建立prefab resource和texture resource引用关系
    ResourceManager -> ResourceManager: 存储prefab resource， 更新注册表
    User <-- ResourceManager: 返回Handle
end

group 资源加载
end
group 资源卸载

end
group 资源销毁

end
....
